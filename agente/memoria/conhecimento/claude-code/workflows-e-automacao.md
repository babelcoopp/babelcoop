# Claude Code 2.1.280 — workflows e automação

Resumo verificado em 2026-09-22 contra os docs oficiais; detalhes nas fontes.

- Workflows dinâmicos: arquivo .claude/workflows/<name>.js (JS puro, não TS/MD); ~/.claude/workflows/ é pessoal; projeto vence em nome igual; vira comando /<name>. Primeira statement obrigatoriamente `export const meta = {name, description}` literal puro (opcionais whenToUse, phases[{title, detail, model?}]); qualquer variável/spread derruba o /<name> do autocomplete.
- API do corpo (fonte: skill /workflow-authoring, não workflows.md): agent(prompt, {label, phase, schema, model, effort, isolation:'worktree', agentType}) → string ou objeto validado (null se parado/erro → sempre .filter(Boolean)); pipeline(items, ...stages) sem barreira, callbacks (prevResult, originalItem, index); parallel(thunks) é barreira e nunca rejeita; log(); phase(); args (JSON real, não string); budget{total, spent(), remaining()}; workflow(nameOrRef, args) só 1 nível.
- Proibido no script: Date.now(), Math.random(), new Date() sem args, import(), filesystem, Node API. Timestamp vai por args.
- Limites: concorrência min(16, CPUs-2) por workflow (env CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS 1-256); 4096 itens por parallel/pipeline; 1000 agentes por rodada; MAX_STRUCTURED_OUTPUT_RETRIES default 5 (1 + 4 retries).
- Agentes de workflow já recebem o CLAUDE.md (não colar a persona Gabriel no prompt); usam as permission rules da sessão — Workflow(<name>) só libera o lançamento; adicionar Read, Bash(python3 scripts/*), Edit etc. em permissions.allow para não pausar. Em auto mode o prompt do agent() conta como texto computado pelo script. Script precisa estar em diretório legível (cwd, /add-dir ou regra Read). MCP autenticado interativamente pode faltar em runs headless/cron.
- Keyword `ultracode` só dispara em prompt humano (não em -p, cron, webhook); /effort ultracode por sessão; settings `ultracode: true` deixa tudo em xhigh (não recomendado). /workflows: s salva, p pausa, x para, r reinicia. Retomada via Workflow({scriptPath, resumeFromRunId}); ler <transcriptDir>/journal.jsonl antes de diagnosticar.
- Settings: workflowSizeGuideline (unrestricted/small/medium/large; default medium, small no Pro; a chave esconde a linha /config; efeito no próximo prompt); enableWorkflows (fora das user settings esconde o toggle Dynamic workflows; não religa se disableWorkflows/env desliga); disableWorkflows = CLAUDE_CODE_DISABLE_WORKFLOWS=1; workflowKeywordTriggerEnabled; subagentPromptCacheTtl 5m/1h; NUNCA disableBundledSkills/CLAUDE_CODE_DISABLE_BUNDLED_SKILLS=1 (remove /deep-research, /workflow-authoring, /loop). Large workflow warning: >25 agentes ou >1,5M tokens, consultivo; guideline própria muda o limiar; ultracode oculta.
- /loop: `/loop 5m prompt` (cron fixo), `/loop prompt` (self-paced 1min-1h via ScheduleWakeup, stop:true), `/loop` sozinho roda .claude/loop.md (projeto vence ~/.claude/loop.md, máx 25.000 bytes) ou prompt de manutenção embutido. Unidades s/m/h/d; recorrentes expiram em 7 dias; jitter (doc: até 30 min; tool: 10% máx 15 min) → usar minuto fora de :00/:30. Esc para self-paced; CronDelete para fixo.
- CronCreate {cron (5 campos, hora local), prompt} obrigatórios; recurring (default true); durable "Has no effect"; additionalProperties false; ID de 8 chars; até 50 tarefas; CronList sem params; CronDelete {id}. Contradição: doc promete restore em --resume, mas a ferramenta diz "gone when Claude exits" — não confiar; regravar lembretes por hook SessionStart. CLAUDE_CODE_DISABLE_CRON=1 desliga tudo. Persistência real: Desktop scheduled task, launchd + claude -p, ou Routines.
- /goal <condição> (1 por sessão, até 4.000 chars, incluir 'ou pare após N turnos'); é um Stop hook prompt-based avaliado pelo modelo pequeno (Haiku; ANTHROPIC_DEFAULT_HAIKU_MODEL); vereditos Not yet met/Met/Impossible; não roda comandos; Ctrl+O mostra a razão; some com disableAllHooks; check-ins 30 min (CLAUDE_CODE_GOAL_CHECKIN_MINUTES, 0 desliga, máx 10080; v2.1.234+, idle v2.1.236+); em -p check-ins só ao fim de turno; não muda permission mode (usar auto).
- Channels: MCP server com capability experimental['claude/channel']: {} e notificação notifications/claude/channel {content, meta (chaves só letras/dígitos/_)}; exige Bun + `@modelcontextprotocol/sdk` (indisponível na máquina sem Node/Bun); custom precisa .mcp.json E --dangerously-load-development-channels server:<nome>; eventos descartados em silêncio se não carregado/bloqueado; entregues juntos se Claude ocupado. Prontos: telegram/discord/imessage (`claude --channels plugin:<name>@claude-plugins-official`).
- Routines: nuvem, clone fresco do default branch (sem arquivos locais), sem prompts, mínimo 1h; /schedule (alias /routines) cria só scheduled; API trigger só pela web (POST /fire com bearer + anthropic-beta experimental-cc-routine-2026-04-01); GitHub trigger via CLI v2.1.225+; prompt disparado não é consentimento (v2.1.213+); precisa login claude.ai (some com API key).
- Headless: claude -p começa em Manual; usar --permission-mode auto|dontAsk + --permission-prompts none (v2.1.259+; remove AskUserQuestion; permission_denied/permission_denials no stream-json); dontAsk nega tudo que pediria prompt, mantém leituras/read-only/allow. --output-format json → result, session_id, structured_output (com --json-schema), total_cost_usd (em --resume/--continue é o total acumulado da conversa; --max-budget-usd ignora o restaurado; print-only, v2.1.217+). --max-turns; --append-system-prompt-file; stream-json --verbose --include-partial-messages. CLAUDE_CODE_PRINT_BG_WAIT_CEILING_MS default 600000, 0 = infinito. SIGTERM → exit 143, roda só SessionEnd, turno inacabado (continua no resume); SIGINT encerra o turno — preferir SIGINT em launchd.
- --bare: pula hooks, skills, commands, subagents, plugins, MCP, auto memory, CLAUDE.md (exceto skills em .claude/skills/ de --add-dir); nunca lê OAuth/keychain; precisa ANTHROPIC_API_KEY OU apiKeyHelper em --settings. Não usar por padrão no babel-os (organismo depende do CLAUDE.md/hooks/memória).
- Babel-os: workflows cruzar-memoria/refinar-substrato/pesquisar-fundo/revisar-organismo em .claude/workflows/*.js com description em PT-BR; permissions.allow com Workflow(<name>) + Read + Bash(python3 scripts/*); loop.md em PT-BR como 'batimento'; dashboard lê meta.name/description via regex, custo por diferença de total_cost_usd, avisos para disableWorkflows/CLAUDE_CODE_DISABLE_CRON/disableAllHooks.
