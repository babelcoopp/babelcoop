- **Nada disto foi commitado nem enviado ao GitHub.** Para levar, copie a pasta `babel-coop` inteira, incluindo as pastas escondidas `.deus/`, `.claude/` e `.github/`. - **Dados da equipe** (diário, pasta compartilhada, bancos locais da Máquina, lixeira): ficam em `~/BabelCoop/` neste Mac. Copie essa pasta também se quiser manter a equipe.

- **Instalador para Mac:** `app/dist/babel-coop-0.1.0-arm64.dmg`. No outro computador: `cd app && npm install && npm run empacotar`.
